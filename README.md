# Ordinance Seven

An adult text romance about five women, a city, and appetite that does not stop. You play a 32-year-old Helix liaison. Days pass for everyone, not only the woman in the room.

Everyone in the story is an adult.

## Play

- **Talk, feed, care, date, be close.** Each woman can refuse a strong or extreme compound until trust, acceptance, or dependency catches up.
- **End the day.** Hunger, habit, and anything still active — Spike, Keel, the ambulatory program, Room bloom — move all five women overnight.
- **Twelve stages,** from Slender to Immobile Blob. Clothes tighten, fail, and get replaced. Each stage has its own body, conversation, event, and intimacy.
- **Helix.** Activate the badge, then buy Nectar-9, Spike, Keel, the Cradle, Bloom serum, Loom clothes, and the sling. The night market sells food and Stillpoint if you want to slow someone down.
- Saves live in this browser. Export a copy from the district screen if you want a file.

## Local

```bash
npm install
npm test
npm run dev
```

Production build (relative URLs, so it works on GitHub Pages):

```bash
npm run build
npm run preview
```

## GitHub Pages

Pushes to `main` and to `cursor/ordinance-seven-6426` run `.github/workflows/pages.yml`, which tests, builds, and deploys with GitHub Actions. In the repository settings, set Pages to **GitHub Actions**. The site is served from the project path with relative asset URLs.
